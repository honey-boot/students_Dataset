# 📘 Student Exam Performance Analysis

This project explores the **Student Performance in Exams** dataset from Kaggle. The aim is to analyze how different factors — like gender, parental education, and lunch type — affect student scores in math, reading, and writing.

---

## 📂 Dataset Overview

- **File**: `StudentsPerformance.csv`
- **Rows**: 1000 students
- **Columns**: 7
- **Source**: [Kaggle Dataset](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams)

---

## 🎯 Objectives

- Compare performance across gender and other demographics
- Investigate if test preparation improves scores
- Test statistical significance of differences using ANOVA and correlation
- Visualize patterns using plots

---

## 🔍 Key Analysis Performed

- **One-way ANOVA**: Check if math scores differ by gender
- **Pearson Correlation**: Analyze relationships between math, reading, and writing scores
- **Group Comparison**: Effect of lunch type and test prep on scores

---

## 📊 Visualizations

- Boxplots comparing scores by gender
- Heatmap of score correlations
- Bar charts showing average scores by group
